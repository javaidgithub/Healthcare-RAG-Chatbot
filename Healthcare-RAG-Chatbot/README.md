# Healthcare RAG Chatbot

An AI-powered healthcare assistant built using retrieval-augmented generation (RAG), LangChain, and multi-dataset retrieval to provide relevant medical information and support workflows.

## Overview
This project demonstrates how large language models can be combined with domain-specific retrieval systems to answer questions using trusted healthcare knowledge sources.

## Features
- RAG-based question answering
- Multi-dataset retrieval pipeline
- LangChain integration
- Healthcare-focused conversational assistant
- Scalable architecture for future enhancements

## Tech Stack
- Python
- LangChain
- Vector Stores / Embeddings
- RAG pipeline
- Jupyter / notebooks

## Prerequisites
- Python 3.10+
- pip
- Virtual environment
- API keys for model provider (if used)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/javaidgithub/Healthcare-RAG-Chatbot.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Healthcare-RAG-Chatbot
   ```
3. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the application:
   ```bash
   python app.py
   ```
